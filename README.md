# Cyberdeck
This cyberdeck is for open-air cracking, encrypted messaging, and general misuse of hardware for the sake of fun.

# Setup
Just plug in the pico and the flipper, then run the setup script.

Running setup:

```
git clone https://github.com/TheHolyTerranEmperor/argcyberdeck.git
mv argcyberdeck /
cd /argcyberdeck
chmod +x ./setup.sh
./setup.sh
```
